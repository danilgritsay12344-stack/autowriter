## 📌 О проекте

**GameSync CLI** позволяет игрокам отслеживать важные игровые события, состояние очередей и изменения баланса прямо из терминала, не открывая браузер во время игровых сессий.

### Основные возможности
- ⚡ **Статус серверов в реальном времени** (проверка доступности и пинга).
- 📜 **Патч-ноуты и апдейты** (вывод кратких чейнджлогов последних патчей).
- 🔔 **Уведомления** при восстановлении работы игровых кластеров.
- ⚙️ **Гибкая настройка** отслеживаемого списка игр через простой `.yaml` конфиг.
